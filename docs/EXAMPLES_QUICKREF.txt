💡 COMMON PATTERNS

Print to console:
  print "Hello, World!"!

Declare constant:
  const PI = 3.14159!

Declare variable:
  var x = 10!

Create function:
  function add(a, b) => {
    return a + b!
  }!

Create class:
  class MyClass {
    var property = value!
    function method() => {
      print property!
    }!
  }!

Use array:
  const arr = [1, 2, 3]!
  print arr[0]!        // First element
  print arr[-1]!       // Last element
  arr.push(4)!         // Add element

Use if/else:
  if condition {
    print "yes"!
  }

Use recursion (loop):
  function loop(n) => {
    if n > 0 {
      print n!
      loop(n - 1)!
    }
  }!
