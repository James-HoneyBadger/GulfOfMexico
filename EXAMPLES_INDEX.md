
## 💡 Usage Examples

### Print Output
```gom
print "Hello, World!"!
```

### Variable Declaration
```gom
const PI = 3.14159!
var counter = 0!
```

### Function Definition
```gom
function add(a, b) => {
   return a + b!
}!
```

### Class Definition
```gom
class Person {
   var name = "Unknown"!
   
   function greet() => {
      print "Hello, I'm ${name}"!
   }!
}!
```

### Array Operations
```gom
const arr = [1, 2, 3, 4, 5]!
print arr[0]!        // First
print arr[-1]!       // Last
arr.push(6)!         // Add
const x = arr.pop()! // Remove
```
